# Rise at Seven - Landing Page Clone

A pixel-perfect clone of the main landing page of **Rise at Seven**, built with modern frontend technologies and smooth interactive animations.

🔗 **Live Demo:** https://riseatseven-landing.vercel.app/

## ✨ Features

- 🎯 Pixel-perfect recreation of the original landing page
- 📱 Fully responsive across multiple screen sizes and devices
- 🎬 Smooth and precise animations
- 🖱️ Interactive hover effects and transitions
- ⚡ Optimized frontend logic for smooth performance and user experience
- 🎨 Carefully crafted UI to closely match the original design

## 🛠️ Tech Stack

- React
- Next.js
- Tailwind CSS
- GSAP
- Lenis
- Swiper
- React Icons
- Lucide Icons

## 🚀 Performance & Optimization

Special attention was given to:

- Smooth scrolling and animations
- Efficient frontend logic
- Responsive layouts
- Optimized rendering performance
- Fluid interactions and transitions
- Maintaining visual consistency across devices

## 📸 Project Goal

The goal of this project was to recreate the original **Rise at Seven** landing page as accurately as possible while ensuring a modern, smooth, and high-performance frontend experience.

## 📦 Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/blindCode13/riseatseven-landing-clone.git
cd riseatseven-landing-clone
npm install
```

## ▶️ Run Development Server

```bash
npm run dev
```

Open `http://localhost:3000` in your browser to view the project.

## 🏗️ Build for Production

```bash
npm run build
npm start
```
